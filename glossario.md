# Glossario

Termo tecnico que aparece nos artigos, explicado sem jargao.

| Termo | O que e |
| :--- | :--- |
| **API** | porta de entrada que um programa abre para outro programa conversar com ele |
| **webhook** | aviso automatico que um site dispara para outro assim que algo acontece |
| **token** | pedaco de palavra que a inteligencia artificial conta para cobrar e medir texto |
| **agente** | inteligencia artificial que decide sozinha os passos ate concluir uma tarefa |
| **prompt** | instrucao em texto que voce escreve para a inteligencia artificial |
| **prompt de sistema** | instrucao fixa que define o comportamento da inteligencia artificial em toda conversa |
| **RAG** | tecnica em que a inteligencia artificial busca em documentos seus antes de responder |
| **MCP** | padrao aberto que conecta a inteligencia artificial a ferramentas e dados externos |
| **JSON** | formato de texto que programas usam para trocar dados organizados |
| **endpoint** | endereco especifico de uma API onde voce faz um pedido |
| **payload** | conteudo de dados que viaja dentro de um pedido entre dois sistemas |
| **no-code** | ferramenta que monta automacoes arrastando blocos na tela, sem escrever codigo |
| **self-hosted** | quando voce instala e mantem o programa no seu proprio servidor |
| **iterador** | bloco que pega uma lista e processa item por item, um de cada vez |
| **roteador** | bloco que separa a automacao em caminhos diferentes conforme uma condicao |
| **parse** | ler um texto bruto e separar os pedacos uteis dele |
| **LLM** | modelo de linguagem, o motor de texto por tras do ChatGPT e do Claude |
| **fine-tuning** | treinar um modelo pronto com exemplos seus para especializar as respostas |
| **contexto** | tudo que a inteligencia artificial consegue ler de uma vez antes de responder |
| **alucinacao** | quando a inteligencia artificial inventa uma informacao e apresenta como verdade |
| **vibecoding** | programar descrevendo o que voce quer e deixando a inteligencia artificial escrever o codigo |
| **execucao** | uma rodada completa da automacao, do gatilho ate o ultimo bloco |
| **operacao** | cada acao individual que um bloco da automacao realiza |
| **gatilho** | evento que dispara a automacao, como um e-mail novo chegando |
| **bundle** | cada item de dados que anda pela automacao, como um e-mail ou uma linha da planilha |
